## 使用场景与验收

### US1 · 在当前会话切换模型和推理强度（P1）

用户可以用 `/model` 和 `/effort` 查看当前设置与候选值，通过补全或传参切换。同一模型重复选择时保留当前强度。切换在下一次请求生效，并继续使用现有会话和请求预算。启动参数可选择受支持的推理强度；未知模型仍可通过原有自定义模型 ID 接入。

### US2 · 查看并缩小上下文（P1）

`/context` 展示消息估算、工具和协议开销、输出预留与剩余空间，使用实际请求预算。`/compact [重点]` 生成更短的摘要，报告压缩前后大小和可恢复的原始归档。失败、取消或摘要未缩小时保留原会话。

### US3 · 在计划和执行之间切换（P1）

用户通过 `/plan`、`/auto`、`/permissions` 或 Shift+Tab 切换模式，状态栏显示生效模式。计划模式允许调查，阻止工作区写入、外部命令和 MCP 工具执行。退出计划恢复进入前的模式。在自动模式，未预先授权的文件修改和外部命令由独立模型请求审查，允许则执行，拒绝则把结果反馈给执行助手。自动审查无需交互批准。拒绝规则始终优先。

## 边界

- 设置的作用域为当前运行中的会话。模型切换沿用当前服务商、入口和凭据。
- `/effort` 由已适配的模型能力决定。首批验证官方 DeepSeek 已接入的模型，Anthropic 强度单独验收。
- 自动审查使用当前配置的模型服务及独立上下文，并计入原请求预算。以本轮用户直接提交的任务为准，同一运行会话中近期的真实用户请求可用于理解“继续”及用户已明确的限制。引用文件、Skill 正文、工具参数和历史模型输出均不能授予权限。无法取得有效结论时拒绝该操作。
- 正在处理的工作采用已开始时的设置。会话关闭或取消期间须确保摘要不会覆盖原始对话。

## 成功指标

- 四个命令均通过终端命令入口验证，选错值或模型不支持时给出明确状态。
- 原会话能从一次成功压缩生成的归档恢复；失败路径保留原会话。
- 计划模式拒绝写入和执行。自动模式无需预配规则即可完成合规的本地编辑和测试命令，拒绝或无有效结论时不运行。原有 CLI 回归通过。
