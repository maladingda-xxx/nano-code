# 实施计划 · 日常终端开发工作流

- **工作分支** `chore/spec-kit`
- **规格** [spec.md](spec.md)
- **日期** 2026-11-18

## 摘要

扩充现有终端命令和共享 Session，完成模型控制、上下文管理及权限模式切换。命令语法与输出约定见 [终端接口](contracts/terminal.md)。

## 技术背景

- Python 3.11+、prompt-toolkit、Rich、SQLite。使用现有 OpenAI 兼容与 Anthropic 适配器。
- 权限判断位于工具分发层，终端直接写入操作遵守计划模式。自动模式保留明确的允许和拒绝规则，其余工作区编辑和命令交给一个无工具的独立审查请求。终端分开传递用户原文与扩展内容。
- 模型切换只改变模型 ID，继续使用同一服务客户端及请求计数。推理强度使用适配器已声明的取值。
- 上下文显示复用请求预算计算。摘要压缩与完整历史归档共用同一数据库事务。

## 项目原则检查

保留 CLI、SDK、RPC 的共享执行及会话格式。既有会话无需迁移。拒绝规则优先，用户配置和已信任的项目可添加自动命令规则。验收以命令入口、工具分发和持久化证据为准。

## 执行顺序

1. 在 `config.py`、`permissions.py`、`runtime.py`、`commands.py` 和 `ui.py` 接入权限模式，并覆盖工具及手动命令。
2. 统一启动和终端的模型配置与推理强度，补齐参数补全和状态。
3. 共享预算计算，完成压缩事务及失败保护。
4. 更新终端文档并运行 Windows 回归。必要时补做已配置模型的真实冒烟。
5. 用无预授权规则的 CLI 任务验证自动审查能放行日常测试。覆盖拒绝、模糊结论、请求异常和取消。
