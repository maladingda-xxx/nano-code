# 评测记录字段

| 记录 | 主要字段 | 校验 |
| --- | --- | --- |
| 候选版本 | Agent 提交、源码改动状态、入口、平台、模型 | 每条结果明确对应验证范围 |
| 固定任务报告 | 任务 ID、目标提交、配置、耗时、请求数、用量、结果和报告目录 | 只读任务核对证据和无修改；修复及功能任务经过候选检查和独立测试 |
| 恢复记录 | N09/N10、操作方式、终端提示、退出/恢复状态、文件标记 | 脚本报告保留 `scripted` 字段，人工操作单独留证 |
| 试用反馈 | 版本、平台、服务、完成结果、审批和等待问题、恢复问题 | 仅纳入实际完成的试用 |

候选补丁初始状态为 `pending_verification`。通过独立测试后变为 `passed`，测试失败则变为 `failed`。没有验证条件的项目保留在任务清单中。
