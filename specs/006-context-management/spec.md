# Feature Specification — Nano Code 上下文管理

**Feature Branch** `codex/006-context-management`  
**Created** 2026-11-20  
**Status** Implemented and verified offline  
**Input** 用户提供的《Nano Code：上下文管理系统架构设计与实现》。

## User Scenarios & Testing

### US1 — 在长任务中监控和控制预算（P1）

**独立验收** 在终端查看预算，然后执行一次产生长日志的工具调用。

1. 短对话正常完成，`/context` 显示当前模型、窗口及来源、输入估算、预留输出、剩余容量、占用与阈值。
2. 长日志被裁剪后，模型仍能看到命令、结果状态、错误和输出末尾，且可按调用引用分页读取已记录的内容。
3. 必要输入超出预算时，请求在发送前停止，终端或事件流显示原因。

### US2 — 压缩后继续原任务（P2）

**独立验收** 用长会话分别触发手动与自动压缩，然后继续调用工具。

1. 摘要保留目标、约束、发现、修改、测试、决策、剩余工作、相关文件和风险。当前请求、最近交互和实际执行状态仍可独立使用。
2. 手动压缩显示估算前后值。自动压缩在配置的压力阈值触发，发送给模型的工具调用和结果仍完整配对。
3. 模型拒绝、超时、空摘要、坏格式、无收益或持久化失败时，原始历史继续可用。重复触发有明确上限。

### US3 — 恢复、分层记忆与用量诊断（P3）

**独立验收** 重启并恢复一个已压缩的会话，切换模型，检查统计。

1. 原始历史可导出，会话继续使用有效摘要，旧会话可以直接恢复。恢复工具结果不会再次执行工具。
2. 工作状态区分工具证据与模型提出的待办。长期项目记忆仅加载相关片段，保留可信度与日期信息。
3. `/context stats` 显示接收到的实际用量、供应商提供的缓存与推理统计、估算误差及压缩裁剪计数，缺失字段保持未知。

### Edge Cases

- 大文件、单行超长、搜索达到上限、命令失败或取消，并覆盖同一批次多个工具。
- 无可压缩历史、最新消息本身放不下、模型请求上限用尽、中断恢复及更换供应商。
- 提示缓存能力不明、用量快照重复、旧会话缺少附加状态。

## Requirements

### Functional Requirements

- **FR-001** 支持模型级窗口及输出上限、估算方法、安全余量和可配置阈值。预算包括工具定义和协议开销。
- **FR-002** 对请求内的工具结果按类型裁剪，保留原始会话记录、明确的省略提示及受限回读入口。
- **FR-003** 在安全工具边界执行结构化手动与自动压缩，保留最近消息和当前任务，失败后使用原有预算回退。
- **FR-004** 持久保存压缩视图所需状态并验证其与原始历史的对应关系。恢复旧会话和中断工作。
- **FR-005** 按相关性加载项目记忆，并跟踪经观察的修改、验证结果和明确待办。
- **FR-006** 保持可复用的提示前缀和确定的工具顺序。仅使用已确认的供应商能力并规范化实际用量。
- **FR-007** 支持 `/context`、`/context stats` 和 `/compact [重点]`，保留终端和脚本诊断能力。
- **FR-008** 使用固定任务和一致配置验证质量、资源消耗、请求与工具次数、耗时和重复操作。

### Key Entities

- **原始会话** 包含用户、助手和配套工具结果，可恢复和导出。
- **请求视图** 包含当前可发送消息、工具定义和对应的预算。
- **压缩记录** 关联原始历史边界、结构化摘要、压缩前后估算和触发原因。
- **工作记录** 包含当前请求、修改与验证证据、任务清单。
- **用量记录** 区分估算和服务端返回的输入、输出、缓存与推理统计。

## Success Criteria

### Measurable Outcomes

- **SC-001** 固定长日志场景中，请求开销低于原实现，错误和末尾摘要仍可见。
- **SC-002** 所有压缩、恢复和失败测试均通过，测试用例的工具配对破损与原始历史丢失均为零。
- **SC-003** 至少验证两类原生协议，包含流式、非流式用量以及已有推理元数据回放行为。
- **SC-004** 报告同任务对照的通过率、用量与工具行为，分别标明离线估算和真实供应商指标。

## Assumptions

- 原始输出指现有工具执行上限内保存的文本。文件位置可以按原工具重新读取。
- 未知模型使用现有保守配置回退。缓存和价格数据按实际可用性报告。
- 多代理上下文隔离及复杂检索在本次范围之外。
