# 状态模型

- **当前会话** 保存活动模型、推理强度、活动权限模式和进入计划前的模式。启动的配置优先级仍适用。
- **模型候选** 是当前服务端点的可选模型 ID 列表。显式输入其他 ID 仍可切换。
- **自动命令** 是 `permissions.autoAllow` 中的精确 `tool`、`cwd` 和 `argv` 规则，经现有项目可信配置规则加载。
- **自动审查** 保存同一会话最近的用户原始请求于进程内。每个决定依赖用户任务与单个动作，模型回复须为精确的 `ALLOW` 或 `DENY`。
- **预算** 含上下文上限、历史估算、工具定义及协议开销、输出预留和剩余输入空间。
- **压缩历史** 继续使用同一个会话 ID。完整原始历史存档到独立 ID，并与替换历史在同一事务提交。
